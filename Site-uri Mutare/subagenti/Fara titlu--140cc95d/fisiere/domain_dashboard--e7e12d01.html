Cum se citesc stările

„Domeniul răspunde: DA” înseamnă că a fost primit un răspuns HTTP, inclusiv o eroare. Un răspuns 404 sau 500 este afișat separat; nu înseamnă că pagina funcționează corect.

„Docker local: DA” înseamnă că există containere asociate pe server. Starea „Activ” cere ca toate containerele asociate să ruleze; verificarea de sănătate este afișată separat.

IP-urile publice provin din DNS și din conexiunea HTTP. Pentru un domeniu protejat de Cloudflare, IP-ul vizibil poate aparține Cloudflare și nu dezvăluie adresa serverului de origine. Serverul Docker local este indicat distinct.

„NU” și „N/A” au sensuri diferite: „NU” este o verificare negativă, iar „N/A” înseamnă că nu s-a putut stabili starea. Lipsa unui Docker local nu înseamnă că domeniul public este inactiv.

Redirecționările pot încărca pagina de pe alt domeniu. Sunt afișate adresa finală și, când sunt disponibile, IP-urile conexiunii inițiale și finale.

Actualizarea la 5 minute recitește datele colectate de server. Ora afișată este ora ultimei verificări a inventarului. Filtrele și rândurile deschise se păstrează la actualizare.

Previzualizările sunt capturi reale ale primei pagini, actualizate în fundal. Data fiecărei capturi este afișată sub imagine. Deschide rândul pentru a încărca imaginile; apasă pe ele pentru mărire într-o filă nouă.
