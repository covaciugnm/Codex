Decompilări și documentație deja existente

Raport principal. Am actualizat situația pe baza inventarelor curente. Rezultatele existente se reutilizează; nu au fost redecompilate pentru această corelare.

„complete-with-documented-limitations” înseamnă că etapa a fost efectuată cu limite consemnate. Rezultatele componentelor pot fi „partial-decompilation”, cu exit code 3 și fișiere Java disponibile. Aceasta nu înseamnă lipsă totală de cod. Numerele Java sunt cele raportate în manifestele de decompilare; nu au fost reverificate individual toate fișierele Java.

AOT se reutilizează oriunde biblioteca are exact același SHA256, inclusiv în variante derivate. Bibliotecile cu hash diferit necesită verificare distinctă; existența unei decompilări Java nu confirmă recuperarea codului Dart.
