# Fotografii de context pentru r02

Aceste fișiere fixează starea de context la pregătirea r02, înaintea reauditului. Sunt copii de conținut create de coordonator, nu o certificare externă. Starea live poate evolua în registrele originale. Auditorii citează aceste copii stabile, nu STATUS, JURNAL, agents.json sau deliverables.json live ca probe cu hash. Validatorul verifică în continuare autorizarea reală în registrul agents.json curent; fotografia nu înlocuiește acea verificare.

Astfel, adăugarea ulterioară a unui agent nou nu schimbă proba istorică a auditului SYS și nu invalidează artificial toate romanele. Schimbarea unui producător/auditor deja implicat sau a intrărilor unui livrabil rămâne supusă controalelor reale. Fotografiile nu se editează după înghețare; noua stare primește altă copie/versiune.
