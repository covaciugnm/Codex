# Probe vizuale de paginare

Versiunea PDF curentă are 28 pagini. control.json enumeră probele actuale: pagina-1.png, pagina-6.png și pagina-7.png. pagina-8.png este păstrată din încercarea precedentă de paginare cu 29 pagini și NU este probă a numerotării curente. În jurnalul observabil se păstrează și randările văzute înainte de ajustarea spațierii. Nu se afirmă că un control de paginare certifică textul literar.
