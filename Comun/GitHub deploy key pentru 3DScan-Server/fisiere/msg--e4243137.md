# Server → iOS: selectorul de motoare (modele, codecuri, versiuni) în Setările aplicației

**Scris:** 2026-10-07 00:47 (Europe/Bucharest)
**Completează:** [2026-10-07_0038_SERVER_CATRE_IOS.md](2026-10-07_0038_SERVER_CATRE_IOS.md)

Proprietarul a cerut ca pe server să fie instalate **toate** variantele concurente fezabile: modele, codecuri, motoare software și versiuni ale aceluiași soft, side-by-side. Fiecare trebuie să poată fi pornită sau oprită din butoane, **atât pe site (`/setari/`), cât și din aplicația iPhone** („sau schimbă aplicația”).

## Ce instalează serverul (echipa `feat/models`, cu audit 10/10)

- **Detectare obiecte:** D-FINE S/M/L, RT-DETRv2, RF-DETR, DEIM etc. Unde chiar dă un câștig măsurat, se activează și ansamblul lor.
- **Vocabular deschis** („cana de lângă monitor”): OWLv2, Grounding DINO, Florence-2.
- **Segmentare:** SAM 2.1 tiny/small/base/large, MobileSAM.
- **Re-identificare:** DINOv2, pentru același obiect între sesiuni și roboți.
- **Sunete:** YAMNet, PANNs, BEATs, AST, CLAP.
- **Voce:** Silero VAD, Whisper tiny → large-v3-turbo, diarizare.
- **Codecuri** (opționale, calea brută rămâne implicită):

| Tip | Variante |
|---|---|
| Video | raw YUV, FFV1, H.264, HEVC, AV1, VP9 |
| Imagine | PNG, WebP lossless, JPEG XL, JPEG |
| Audio | PCM, FLAC, WavPack, Opus, AAC |
| Adâncime | raw f32, zstd/lz4, RVL, PNG16 |
| 3D | PLY, Draco, GLB, LAZ |

- **Reconstrucție:** Open3D TSDF (două variante), alternative CPU, nvblox (doar GPU).
- **Backend-uri de inferență:** ONNX Runtime, OpenVINO, TensorRT (doar GPU).
- Fiecare intrare are o etichetă de **licență** (comercial / cercetare / neclar) și **cpu/gpu**. Setul de cercetare e oprit implicit.

## Ce faci în iOS

1. **`GET /api/app/settings`:** aplicația citește setările pe care trebuie să le respecte:
   - codecul de transport pentru fiecare flux (implicit **raw**);
   - ce fluxuri trimite;
   - rezoluția și cadența;
   - ce rulează pe telefon și ce pe server.

   Le aplică live când primește notificarea de schimbare (SSE/WebSocket, formatul e în contract).
2. **Ecranul Setări → „Motoare”**, vizibil doar pentru un utilizator **admin**: aceleași controale ca pe site (`PUT /api/admin/engines`, aceeași autorizare). Grupurile sunt pe sarcini, cu buton pornit/oprit, alegerea implicită per sarcină, badge-uri de licență și cpu/gpu, starea (încărcat / oprit / eroare cu motiv) și memoria. Fiecare comutare apare în jurnalul de audit cu sursa „aplicație”.
3. **Motoarele de pe telefon** (detectorul Core ML, AuraFace etc., care au deja selector în aplicație) se raportează în același registru. Așa, proprietarul vede într-un singur loc tot ce rulează și unde.
4. **Cheile i18n** pentru ecran se adaugă în toate cele 7 limbi.

Contractul exact: `Site/docs/SETARI_MOTOARE.md` pe `feat/models`. Devine final după auditul 10/10 și merge-ul pe `main`. Te anunț aici, cu un fișier nou cu oră.

## Dacă iOS nu poate

Dacă un codec sau o variantă nu se poate face eficient pe telefon (de exemplu FFV1 sau JPEG XL lossless în timp real, din cauza encoderelor hardware disponibile), scrie asta într-un fișier `..._IOS_CATRE_SERVER.md`. Serverul îl marchează „doar server” și nu-l mai oferă ca opțiune de transport pe telefon.
