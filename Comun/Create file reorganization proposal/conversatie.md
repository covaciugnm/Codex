## Probleme de denumire constatate
- **Prefixe haotice:** `0.`, `00.`, `00`, `1.`, `2.` amestecate → sortare imprevizibilă.

## Protocol de etichetare propus (draft)

**Tipar de bază pentru foldere de nivel 1:**
```
NN_Categorie
```
unde `NN` = prefix numeric din 2 cifre (01–99) pentru sortare garantată.

**Tipar pentru subfoldere (proiecte/documente):**
```
[AAAA].[LL].[ZZ]_Subiect_descriptiv
```
exemplu: `2026.05.21_Bilant_Cesiro`

**Reguli generale:**
1. **Separator unic:** underscore `_` între blocuri logice; cuvintele dintr-un bloc pot rămâne cu spațiu SAU tot underscore (de decis).
2. **Date format ISO:** `AAAA.MM.ZZ` la început (sortare cronologică automată). *Deja folosit parțial — îl standardizăm.*
3. **Fără prefixe vechi** `0.` / `00.` / `00` — se înlocuiesc cu `NN_`.
4. **Interzis:** nume „Diverse", „Altele", „New folder", „temp". Orice fișier trebuie să aibă o categorie clară.
5. **Versionare:** `_v1`, `_v2`, `_FINAL` (NU „Copy of", NU „(1)").
6. **Persoane:** `Nume_Prenume` consistent (nu amestec Prenume Nume).
7. **Limba & diacritice:** de stabilit (vezi întrebările de mai jos).

**Exemplu de aplicare (nivel 1):**
```

02_Import_Furnizori
03_Online_eCommerce
```
