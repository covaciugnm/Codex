## Cum se folosește fără recitirea arhivei

1. Caută firma, referința ofertei sau tema în Excel, JSON ori SQLite.
2. Verifică data și dimensiunea fișierului relevant față de inventar. La modificare, actualizează indexul; nu folosi textul vechi ca sursă curentă.
3. Citește rezumatul verificat și textul salvat. `ce_reprezinta` este o clasificare dedusă din nume, iar `extras_continut` este un fragment automat; nu sunt rezumate umane complete ale fiecărui document.
4. Pentru decizii, confirmă în original sumele, condițiile, căsuțele bifate și semnăturile. Câmpurile PDF și anotările vizibile pot diferi: răspunsul TOMS din 28.09 a fost verificat și vizual.
5. Consultă cea mai recentă corespondență disponibilă. „Nu apare local” nu înseamnă „nu a răspuns în email”.

Exemplu PowerShell, din folderul clădirii:

```powershell
& 'C:\Users\User\AppData\Local\Programs\Python\Python312\python.exe' -X utf8 'folder map\cauta.py' 'Bauwerksbuch' --folder '04. Firme' --limit 8
```

Actualizare incrementală:

```powershell
& 'C:\Users\User\AppData\Local\Programs\Python\Python312\python.exe' -X utf8 'folder map\actualizeaza_index.py'
```

Extractorul recalculează hash-ul numai pentru fișierele noi/modificate după dimensiune și timpul de modificare și reutilizează textele salvate. Pentru noi scanuri: rulează `completeaza_ocr.py`, apoi din nou `actualizeaza_index.py`.
