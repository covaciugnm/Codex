INSTRUCȚIUNI PENTRU PREGĂTIRE - SE ELIMINĂ DIN DOCUMENTUL EMIS:
1. Acest fișier este un model pregătit pentru bancă/IFN. El nu atestă efectuarea analizei sau acordarea vreunei finanțări.
2. Instituția emitentă completează toate câmpurile și păstrează mențiunile obligatorii din ghid. Scrisoarea se emite pentru solicitant, nu pentru grup sau asociat.
3. Suma se corelează cu necesarul pentru contribuția proprie și cheltuielile neeligibile din bugetul final. Nu se completează numai pe baza ofertei de baterii.
4. Data este cea reală a emiterii. Scrisoarea se obține înainte de depunerea efectivă a cererii, nu abia la contractare.
5. Scrisoarea nu înlocuiește bilanțurile, hotărârea AGA/asociatului unic, declarația unică sau condiția de neîncadrare în dificultate.
6. Câmpurile privind numărul, data, antetul și semnătura sunt pentru identificarea documentului emis; rubrica de valabilitate este propusă pentru claritate și nu reprezintă o cerință de șase luni din ghid.
